# Line Segment Analyzer

Line Segment Analyzer is a browser-based tool for detecting and visualizing line-segment structures in images.

This repository contains the source code used for illustrative geometric analyses, including detection and visualization of representative line structures, parallel relationships, equal-interval relationships, and ratio-based spatial patterns.

## 🚀 Live Demo

The online version is available here:

**https://hubgit86se.github.io/line-segment-analyzer/**

## Features

* Browser-based image analysis
* Line-segment extraction
* Representative line visualization
* Parallel-line relationship detection
* Equal-interval relationship detection
* Ratio-relationship detection
* Graphical visualization of detected structures

## Files

* `index.html`
  Main HTML file.

* `main.js`
  Main JavaScript implementation.

* `libs/`
  Third-party libraries, including OpenCV.js if included locally.

* `img/`
  Sample or related image files.

## How to Use

1. Open `index.html` in a web browser.
2. Load an image.
3. Run the analysis.
4. Review the detected line structures and visual outputs.

No server-side processing is required. Image analysis is performed locally in the browser.
